# 📝 ReactBlog - 리액트 기초 학습 프로젝트

리액트(React)의 핵심 개념인 **State, Props, Component**를 학습하고 실습하기 위해 제작된 간단한 블로그 웹 애플리케이션입니다.



## 🚀 주요 기능

### 1. 게시물 관리 (CRUD)
* **글 발행**: 하단 입력창에 내용을 작성하면 리스트 최상단에 새로운 포스트가 추가됩니다.
* **글 삭제**: 각 포스트 옆의 '삭제' 버튼을 통해 게시물을 제거할 수 있습니다.
* **자동 날짜 생성**: 게시물 발행 시 현재 날짜가 자동으로 기록됩니다.

### 2. 인터랙션 (Interaction)
* **좋아요(👍)**: 각 게시물마다 개별적인 좋아요 카운트가 작동하며, 클릭 시 숫자가 증가합니다.
* **상세 보기 (Modal)**: 글 제목을 클릭하면 선택한 글의 제목이 담긴 상세 모달창이 나타납니다.
* **정렬 기능**: '가나다순정렬' 버튼을 클릭하여 목록을 이름순으로 정렬할 수 있습니다.

### 3. 기술적 특징
* **State 불변성 유지**: 원본 데이터를 직접 수정하지 않고 `[...]` (Spread Operator)를 사용하여 복사본을 생성 후 변경하는 React의 관습을 준수했습니다.
* **이벤트 버블링 방지**: 좋아요 버튼 클릭 시 모달창이 함께 뜨지 않도록 `e.stopPropagation()`을 적용했습니다.
* **컴포넌트 기반 설계**: 반복되는 UI와 상세 페이지를 `Modal` 컴포넌트로 분리하여 관리합니다.
